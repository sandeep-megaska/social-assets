# social-assets

Public images and videos for the @megaska.brand and @chatji.ai Instagram and Facebook posts, served by GitHub Pages so the Instagram publishing API can fetch them by URL.

- `megaska/YYYY-MM/…`: Megaska posts
- `chatji/YYYY-MM/…`: Chatji posts

URL pattern: `https://sandeep-megaska.github.io/social-assets/<path>`

Only media meant to be posted publicly goes here.
